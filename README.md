# Git Reset Lab

A practical repository for learning Git and GitHub through hands-on exercises.

## Contents

- Bash server health-check script
- Git branching and merging exercises
- Git ignore rules
- Repository management practice

## Requirements

- Git
- Bash
- Linux or a compatible Unix-like environment

## Running the Health Check

Make the script executable:

    chmod +x scripts/health-check.sh

Run it:

    ./scripts/health-check.sh

## Purpose

This repository is used for learning version control, collaboration, and basic server operations.
